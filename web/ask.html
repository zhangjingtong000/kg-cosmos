02 — 提问

问一句，证据自己站队。

系统在图上按字面命中种子实体，沿关系做两跳扩展，得到一小片子图； 然后由多个 Agent 各自给出立场——每条立场都必须挂在某一篇原文的那一句上。 答案可以含糊，证据不行。

问题落在某一篇论文的图上（检索实体与边）

01字面命中种子 长名字优先，被更长命中包含的短名字直接丢掉，否则「TransE 的局限」会同时命中 Tran
02两跳扩展子图 BFS 两跳，封顶 70 个节点；命中的实体与路径在图上高亮
03多 Agent 各自站队 支持方与反方分开取证，每条证据附原文摘录与出处，最后给一句综合判断
01在社区摘要上匹配 不查某一篇论文的实体与边，而是把问题与全库的社区摘要做词面匹配，取最相关的几个社区
02证据是社区级的 每个社区一段概括，由本地模型根据该社区的实体与关系生成 —— 它不是论文原文，也没有页码
03同一套四步链路 支持方与反对方独立读同一批社区摘要，综合方只看两方交上来的东西

检索之后，子图、双方证据与综合结论会依次展开在这一页里。
