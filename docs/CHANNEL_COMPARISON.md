## 结论（初步）

1. **实体召回高、精确低**：两篇的实体 R 均在 0.9 以上而 P 约 0.25。诊断显示 FP **零幻觉**、全部有原文依据——抽取器按提示词要求「抽所有明确提到的实体」，因而把论文结构词、示例数据、被引作者一并抽出。这是**任务定义粒度差异**，不是模型缺陷。

2. **显著性随领域变化极大**：文献计量论文的结构噪声占 22.4%，系统论文仅 3.0%。领域命名越规范，抽取器越不容易把脚手架当实体。

3. **关系抽取是稳定短板**：两篇的 F1 均低于 0.06。抽取器产出大量 `RELATED_TO` 泛关系，而金标只承认有句级依据的具体关系。这是蒸馏最明确的改进靶点。

4. **一致率决定置信边界**：两篇的四方一致率为 67.3% / 73.1%，故上述 P/R/F1 应连同一致率一起报告，不宜作为绝对真值引用。
