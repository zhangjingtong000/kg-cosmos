# 抽取通道对比（M2 实验）

> ## ⛔ 本文档的 P/R/F1 指标已被证伪，不得作为质量主张引用
>
> 2026-09-11 的诊断（`tools/diagnose_gold_metrics.py`、`tools/diagnose_relations.py`）
> 证明下表的 P/R/F1 **没有解释力**，原因有三条，均有数据支撑：
>
> 1. **规模口径错配**：金标 93 实体 vs 系统 344，比值 3.70。P 的数值主要由
>    `|G|/|S|` 决定，而非抽取精度。两篇论文都出现同一比值（3.70 / 3.66）。
> 2. **88.3% 的"错误"实体名字字面出现在其原文证据里**（256 个 FP 中 226 个）。
>    若这些是错误抽取，名字不可能在原文中找到 —— 它们只是未被金标收录。
> 3. **关系金标本身没有标注者间共识**：Krippendorff α = **-0.0119**（论文1）/
>    **-0.1465**（论文2），接近随机。分母无共识 ⇒ 相除无意义。
>    且谓词口径消融三档 F1 **完全相同**（0.043/0.043/0.043）⇒ 谓词不是瓶颈。
>
> 权威论文的独立佐证：arXiv 2305.14450 实测 CoNLL04 错误构成中
> **Unannotated spans 占 33.94%** 而 **Incorrect types 仅 3.43%**；
> arXiv 2504.04083 原文指出 *"false positives appear to be correct relations
> missed by the annotators ... artificially severely deflate performance"*。
>
> **结论**：下表数据仅作原始记录保留。**"本地 9B 优于云端"的推论不成立** ——
> 两者只是处于不同 PR 工作点（云端 344 输出高召回低精度、本地 141 输出保守），
> 单点 P/R/F1 不足以支撑模型优劣结论。
> 详见 `docs/PHASE_REVIEW_2026-09-11.md` 与 `docs/GOLD_METRIC_DIAGNOSIS.md`。

> 生成脚本：`tools/compare_channels.py`；每篇的金标与范围见对应评分 JSON。

> 评分口径：实体匹配用严格（归一化全等）与宽松（相似度 ≥0.93 且通过长度保护）两级，正文报告宽松口径；关系按 (源, 目标, 类型) 归一后全等记命中。

## 结论（已被 2026-09-11 诊断推翻，保留原文以记录判断演化）

> ⚠️ 以下 4 条结论**均不再成立**，逐条给出推翻理由。保留原文是为了记录判断如何演化，
> 避免后来者重复同样的推理。

1. ~~**实体召回高、精确低**：……这是任务定义粒度差异，不是模型缺陷。~~
   **部分正确但表述不够**：诊断确认零幻觉（FP 100% 带原文证据、88.3% 名字字面在证据中），
   但真正原因是**规模口径错配**——金标答"重要知识实体"（83 个四方共识），
   系统答"全部可命名实体"（344 个），**两者测量的不是同一个集合**，相除无解释力。

2. ~~**显著性随领域变化极大**~~：**这一条仍然成立**，且是本文档唯一可保留的发现。
   文献计量论文结构噪声 22.4% vs 系统论文 3.0%。领域命名越规范，
   抽取器越不容易把脚手架当实体。

3. ~~**关系抽取是稳定短板**……这是蒸馏最明确的改进靶点。~~
   **已推翻**：关系 α ≈ 0 说明金标本身无共识；
   谓词口径消融三档 F1 完全相同说明**谓词不是瓶颈**；
   权威论文实测 Incorrect types 仅占错误 3.43%。
   **关系 F1 低不是抽取短板，是评测协议缺陷**，改进靶点不在蒸馏。

4. ~~**一致率决定置信边界**：……故上述 P/R/F1 应连同一致率一起报告~~
   **已推翻**：成对 Jaccard（67.3% / 73.1%）**不是 chance-corrected 量**，
   不能称为"一致率"，应改名"成对集合相似度"。
   正确的量是 **Krippendorff α**：实体 α = 0.2312 / 0.2880（低），关系 α = -0.0119 / -0.1465（≈随机）。
   且一致性 ≠ 效度（CLPsych 2025）：同模型高一致率不能作为金标可信的证据。

### 现在可以主张的（替代上述结论）

1. **图结构质量可信**：本体违规 0、自环 0、重复名组 0、证据完整度 100%、Louvain 模块度 0.675。
2. **显著性指标有效**：结构/泛指词占比可直接量化"抽取器分不清知识实体与论文零件"这一缺口，
   且该比例不需要额外金标。
3. **关系层的负结果本身是发现**：4 个独立 LLM 标注者在实体层达到 α ≈ 0.23–0.29，
   在关系层降到 α ≈ -0.15–-0.01。**实体层与关系层的任务歧义性存在量级差异**，
   这说明开放域关系抽取需要比"是否存在关系"更结构化的定义
   （如 GraphRAG 的 claim + status + 引用 + 时间四元组，见 `docs/早先的阶段计划.md` T3.3）。
