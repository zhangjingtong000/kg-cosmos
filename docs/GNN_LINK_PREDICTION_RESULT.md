# GNN 链接预测实验结果（H7「不上 GNN」复检）

**环境**：`torch 2.6.0+cu124`，CUDA 可用（RTX 4060 Laptop）；**没有 PyG、没有 DGL**，有 `pykeen 1.11.1` ⇒ GNN 用纯 PyTorch 手写（2 层 R-GCN + DistMult），KGE 基线用 pykeen TransE。
**数据**：`data/corpus/graphs/*.json` 的 **17 篇英文**（43,867 三元组 / 19,469 实体 / 15 关系）。选它因为它是唯一**逐篇带论文归属**的完整快照（跨论文划分必须要这个信息），且与 H6 同口径同种子，**复现出完全相同的留出论文**。不用 `web/kg-data/nebula.json`：那是 3D 渲染的降采样（30k 边上限 / 9 篇论文 / 带 xyz 坐标、边被抽稀）。
**划分**：**A** 随机切 10% 的边（transductive，测试 4,386 条）· **B** 整篇留 3 篇 `1703.08098v9` / `2402.12001v1` / `2502.00681v2`，再分 **B1** 两端实体训练时都见过（H6 口径，1,027 条）与 **B2** 全量（真 inductive，5,394 条）。B 中涉及训练未见实体的边 **4,367 条 = 80.96%**，即 H7 引用的那个数。
**方法**：启发式 PA/CN/AA（只用训练图结构）；KGE = pykeen TransE；手写 GNN = 2 层 R-GCN + DistMult（每关系权重矩阵 + 度归一化），输入特征三选一 —— `ID` 可学习嵌入（transductive）/ `TYPE` 16 类 one-hot / `TEXT` 1024 维 bge-m3 实体名嵌入；`MLP-*` 是同特征、同解码器、同损失但**不做消息传递**的消融。指标 **AUC**（每边 20 尾 + 20 头 filtered 负样本）与 **Hits@10 / MRR**（filtered 全实体排名，head/tail 双向平均），所有方法共用同一段评测代码与同一批负样本。

| 方法 | A AUC | A H@10 | B1 AUC | B1 H@10 | B2 AUC | B2 H@10 |
|---|---|---|---|---|---|---|
| Random | 0.5038 | 0.0003 | 0.4989 | 0.0000 | 0.5013 | 0.0003 |
| PA | 0.6071 | 0.0522 | 0.7658 | 0.0857 | 0.4415 | 0.0163 |
| CN | 0.7065 | 0.1632 | 0.7176 | 0.1500 | 0.5337 | 0.0286 |
| AA | 0.7089 | 0.1927 | 0.7180 | 0.1495 | 0.5337 | 0.0285 |
| TransE（见下） | 0.5467 | 0.0049 | 0.4592 | 0.0180 | — | — |
| GNN-ID | 0.7434 | 0.0719 | 0.8066 | 0.1003 | 0.4780 | 0.0194 |
| GNN-TYPE | 0.7739 | 0.0540 | 0.8161 | 0.0847 | 0.6113 | 0.0226 |
| GNN-TEXT | 0.7785 | 0.0690 | 0.8154 | 0.0910 | 0.5852 | 0.0335 |
| MLP-TYPE（消融） | 0.6612 | 0.0000 | 0.7064 | 0.0000 | 0.6580 | 0.0000 |
| MLP-TEXT（消融） | 0.6960 | 0.0530 | 0.7090 | 0.0954 | 0.6404 | 0.0366 |

**AUC 与 Hits@10 的结论不一致，必须并列看**：设定 A 里 **AA 的 Hits@10 = 0.1927、CN = 0.1632，高于所有 GNN**（GNN 最高 0.0719）；B1 同理（CN 0.1500 > GNN-ID 0.1003）。原因是启发式打分稀疏（绝大多数候选中 0 分，真值一旦非零就排前），而 GNN 打分稠密、绝对校准差 —— **AUC 只比较同一 (h,r) 下正负样本的相对序，全实体排名还要求跨候选的绝对校准**。MLP-TYPE 的 Hits@10 = 0 是同一问题的极端形态：16 类 one-hot 无法区分同类型实体，排名完全并列。
**结论（H7 对的那一半）**：纯结构方法在跨论文设定下确实失效 —— GNN-ID 在 B2 上 AUC 0.4780 **低于随机**；消融进一步显示消息传递在 B2 上**帮倒忙**（完全不用图的 MLP-TEXT 0.6404 / 0.0366 反超 GNN-TEXT 0.5852 / 0.0335），而在 A / B1 上 GNN-TEXT 远高于 MLP-TEXT（0.8154 vs 0.7090）⇒ **新实体在训练图里没有邻域，卷积无从下手，这正是 H7 讲的机理**。
**结论（H7 不成立的那一半）**：带内容特征的模型在**同一个跨论文划分**下是赢的（B2 AUC 0.585–0.640 vs 启发式 0.534），所以"跨论文 ⇒ 不上 GNN"推不出来；H7 真正站得住的理由是**所有方法绝对指标都极低**（B2 上 Hits@10 ≤ 0.037），即这个图谱的链接可预测性本身就差 —— 但这条理由与用不用 GNN 无关，换任何模型都一样。**一句话：不是"GNN 不适合"，而是"这个任务本身太难，GNN 能赢但赢得不值得"。**
**TransE / KGE 基线的实情**：首轮（150 epoch）TransE 抛 `ValueError: Must specify either dataset or both training/testing triples factories`（`pykeen.pipeline` 只传了 `training` 没传 `testing`）⇒ **该轮 KGE 基线完全没跑起来**。改用底层 `SLCWATrainingLoop` 后跑通（上表数字），但**未对训练时未见实体做 mask**（它们被填 0 向量）⇒ TransE 的 A / B1 数字是**下界**，B1 的 0.4592 低于随机即由此 artifact 造成；修 mask 的那轮运行被环境重启打断，未落盘，故脚本现状与产物在这一点上不一致。
**不确定之处**：① 未调超参、早停只切 5% 训练边（GNN 最佳 valid epoch 落在 30–60，总 80，是收敛的）⇒ 表中数字都是**下界**；② 划分 B 只留 3 篇，敏感性扫描（每种 30 次随机切分）给出新实体边比例 min 70.4% / 中位 77.7% / max 92.2%（21 篇口径 68.2% / 78.1% / 89.6%）⇒ **80.96% 是点估计，但"高比例"这一定性判断稳健**；③ Hits@10 用平均排名处理并列。
