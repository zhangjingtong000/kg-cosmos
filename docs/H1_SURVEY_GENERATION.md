## 二、★ 那个"实验章新指标"是什么

**它不是"让模型写篇综述"** —— 那随便一个模型都能写。
它要回答的是：**"能不能生出一段**每句话都能被核对**的综述？"**

⇒ 所以做法是**先让引用可被机械解析**，再**机械核对**：

**给模型的证据是带编号的**：
```
[E1] Embedding Models --APPLIES_TO--> Knowledge Graph Completion（1703.08098v9 第 1 页）
[E2] Embedding Models --RELATED_TO--> Real-world objects represented in knowledge graphs（…）
```
**要求它每句末尾写 `[E1][E3]`。**

然后四个指标（**全部零 LLM 判分**）：

| # | 指标 | 算法 |
|---|---|---|
| ① | **句句溯源率** | 有引用的句子 / 总句数 |
| ② | **引用有效率** | 引用编号真的在证据表里的比例（**防编造**） |
| ③ | **接地率** | 句里提到的实体**都在**它所引的证据里 |
| **★④** | **主张-证据支持率** | 同时满足①②③的句子 / **可判定**句数 |

**⑤ 可判定率**（④的配套）—— 见 §四。

**为什么不用 LLM 判分**：本项目已量过四个模型标注者对关系层的一致性 α 是**负的**；
**用一个 α 为负的裁判给另一个模型打分，得到的分数没有意义。**

## 三、结果（两个话题）

| 话题 | ① 溯源 | ② 有效 | ③ 接地 | ⑤ 可判定 | **★④ 支持率** |
|---|---|---|---|---|---|
| `knowledge graph embedding` | 100% | 100% | 75% | 100% | **75%**（分母 4） |
| `link prediction` | 100% | 100% | 75% | 75% | **100%**（分母 3） |

**① ② 都是 100%** —— 模型**没有编造过引用编号**，而且**每句都标了引用**。
**③④ 有差异**，说明指标**能区分好坏**（不是恒等于 100%）。

### ★ 那个 75% 是抓到了一个**真错误**，不是噪声

话题 A 里那句被判 `ungrounded` 的：

```
句子："具体而言，知识图谱中的节点由向量 $v_h$ 或 $v_t$ 表示，这些嵌入直接应用于知识图谱结构。"
引用：[E4][E6]
语义判定出句中提到的实体：'A node in a knowledge graph, represented by a vector vh or vt.'
```

**E4 / E6 说的是**：
```
[E4] Embedding Models --APPLIES_TO--> Knowledge Graphs
[E6] Embeddings --APPLIES_TO--> Knowledge Graphs
```

**⇒ 句子讲的是"节点用向量表示"（那条证据是 `E5`），却引了"适用于知识图谱"的 `E4`/`E6`。**
**正确做法是引用 `[E5]`。** ⇒ **这是一个真实的溯源错误，判据准确地抓住了它。**

## 四、⚠️ 两个"必须一起报"的配套指标（这一节是本实验的方法学部分）

### ① 三态，不是布尔

第一版把"句子有没有提到证据实体"做成布尔，**`mention 为空 ⇒ 判成"不接地"`**。
一跑就暴露：模型写**中文散文**、证据是**英文实体名**，字符串匹配**一个都对不上**
⇒ 句子全被归成失败。**而它们其实写得没错**（引用是准的）。

⇒ 改成三态：
```
grounded      句里提到的实体都在所引证据里
ungrounded    提到了一些、但有不在所引证据里的   ← **真问题**
unjudgeable   一个证据实体都没提到               ← **无从判断**
```
**④ 的分母排除 `unjudgeable`** ——
否则"没提到实体"会被当成"错"，**指标就变成了惩罚文体而不是度量接地**。

### ② 但 ④ 必须与 **⑤ 可判定率** 一起报

**因为分母可能很小。** 实测 `link prediction` 那一跑：
**5 句里 3 句 `unjudgeable`（60%）⇒ ④ 的"100%"分母只剩 2 句。**
**那个 100% 单独看会严重误导。**

⇒ 所以加了 **⑤ 可判定率**，并把它印在 ④ 的上一行。

### ③ 跨语言判定：借 `embeddings.py` 的 bge-m3

字符串匹配对中文失效 ⇒ 用**多语言嵌入**判"这句话是不是在说这个实体"
（`bge-m3`，项目本来就为 H4 装好了，本轮还顺手修好了它）。

**先试字符串、再试嵌入** —— 顺序是有意的：
字符串**准且快**，而且它**不会**把 `Hits@10` 误判成"在说 `Knowledge Graphs`"。

**实测效果**（同一话题 `link prediction`）：
```
              修前      修后
③ 接地率       40%  →   75%
⑤ 可判定率     —   →   75%
unjudgeable    3 句 →   1 句
```
而剩下那 1 句 `实体=[]` 是**判对了** ——
「该任务旨在对三元组进行预测与应用」**句子本来就没提实体**（代词/泛指），
**那是真实的文体现象，不是判据的问题**。

**嵌入服务不可用时自动退回字符串匹配** ⇒ 这份工具在没有 Ollama 的机器上仍能跑。

## 五、诚实的边界

| # | 边界 | 影响 |
|---|---|---|
| **1** | **只有 2 个话题、各 1 段** | 4–5 句/段 ⇒ **指标的分母是个位数**，绝对值不该当结论 |
| **2** | **`GROUND_TH = 0.55` 是试出来的** | 比 H4 的 `HIGH=0.93` 松得多（比的是"一整句话 ↔ 实体名"，语义密度差一个量级）；**没做阈值敏感性分析** |
| **3** | **`ungrounded` 里可能混有"判据过严"** | 句子可能同时涉及 `E5` 与 `E4` 两件事却只引一个 ⇒ **会算作不接地** |
| **4** | **没有人类对照** | "这段话作为综述写得好不好"**没人评过** —— 本实验只度量**可核对性**，不度量**可读性/完整性** |
| **5** | **证据是"按话题词匹配 + 有页码优先"挑的** | 挑证据的方式会直接影响能写出什么；**没有做"换一种挑法"的对照** |

**第 4 条最要紧**：**这份指标度量的是"每句话有没有出处"，不是"这段综述写得好"。**
把 ④ 当成"综述质量分"是误读 —— **它只覆盖"接地"这一个维度**。
