## 二、关系层 TP = 0 的根因：**两边对"实体"的定义不同**

诊断（一次性探针 + 产物里的 `sample_fp`）：

**第一篇抽取出来的实体**：
```
'Image Restoration' · 'gradient vanishing' · 'ill-posed inverse problem'
'corruption distributions' · 'computer vision tasks' · 'corrupted images'
'clean ones' · 'super - resolution' · 'compression artifacts reduction'
'input' · 'output' · 'residual of the problem'
```

**SciREX 金标要的**：
```
RED30（方法名）· Image_Super-Resolution（任务名）
PSNR / SSIM（指标名）· BSD100_-_4x_upscaling / Set5_-_4x_upscaling（数据集名）
```

**⇒ 本项目抽的是"知识概念"，SciREX 标的是"专名"。**
`RED30` 与 `PSNR` **从未被抽成实体** ⇒ 以它们为主语/宾语的三元组**不可能命中**。

**还有一处归一问题**：抽出了 `'super - resolution'`（fold 后 `superresolution`），
而金标是 `Image_Super-Resolution`（fold 后 `imagesuperresolution`）—— **包含但不相等**。
**即使专名抽出来了，`fold` 的精确匹配也会漏掉这类"金标更完整"的情况**，
需要子串/别名匹配才能救回一部分。**但那是第二层问题，第一层是根本没抽出来。**

## 三、★ 这修正了原先的假设（诚实记录）

**我原先的假设**（写在 `TODO.md` 的 P6 里）：
> 「若在**槽位式**协议上表现明显好于我们自己的**开放式**谓词，
> 就从'抽取侧'印证了**可标性取决于协议结构化程度**。」

**实测结果既没有印证、也没有推翻它 —— 而是指向了一个更基础的原因**：

| | 原先以为的差别 | **实测到的差别** |
|---|---|---|
| **变量** | 协议结构化程度（槽位式 vs 开放式） | **"实体"的定义不同**（专名 vs 知识概念） |
| **结果** | 槽位式上应该更好 | **根本没抽出来（0/40）** |

⇒ **正确表述**：
> **SciREX 与本项目做的是两个不同的任务。**
> 它要「**方法 —在哪个数据集上— 达到什么指标**」，是一张**实验对比表**的机器可读化；
> 本项目要「**这批论文在讲什么、谁和谁有分歧**」，是一张**领域知识地图**。
> **关系层 TP = 0 不是"我们抽得差"，而是"我们根本没在抽那种东西"。**

**这反而给主研究点补了一刀更有力的论证**：
**"可标性/可抽性取决于协议"** 这件事，比原先设想的**更彻底** ——
**不只是"标注一致性"层面，连"什么算一个实体"这个最底层的约定都不同。**
SciREX 之所以能产出 2148 条**人类一致标注**的关系，是因为它的协议**先把
"Method/Task/Material/Metric 是实体"这件事固定死了** ——
标注者不需要判断"这算不算一个值得进图的实体"。
