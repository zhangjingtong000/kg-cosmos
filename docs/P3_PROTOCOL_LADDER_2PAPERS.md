## 二、两篇一致的（**可以当结论**）

### ① 「完全开放」的一致性都是负的

```
A: α = −0.2977
B: α = −0.1783
```

**两篇都负，且都不是接近 0 的负。**
⇒ **「完全开放的谓词空间下，标注者之间无法产生共识」是可复现的。**

### ② 「给类型表」带来跃升

```
A: −0.2977 → −0.2209   （+0.0768）
B: −0.1783 → +0.1673   （+0.3456）
```

**两篇都升，B 升得更猛。**
⇒ **"把谓词空间收窄"是改善一致性最有效的一步。**

### ③ ★ 「输出收敛度」单调下降 —— **两篇都完美单调**

```
A: 类型数  29 → 10 → 9 → 3
B: 类型数  26 → 10 → 8 → 2
```

**这条比 α 更干净、更稳**，它是"协议结构化程度"的**操作性度量**：
**模型被允许发挥的余地越小，它实际用到的类型越少。**

⇒ **若论文里只报一个数，应该报这个** ——
它两篇都单调，且**不依赖 α 的小样本问题**。

## 三、两篇不一致的（**必须如实说明**）

### ⚠️ 档 4 在第二篇上**回落**

```
A: 档3 −0.0243 → 档4 +0.4179   （大幅上升）
B: 档3 +0.2784 → 档4 +0.2174   （小幅回落）
```

**⇒ 所以不能说"α 随结构化程度单调上升"。** 只能说：
**「从完全开放到给类型表，α 显著提升；继续收紧不保证继续提升。」**

### 档 4 为什么不可靠：**样本少到算不出稳定的 α**

```
B 档 4: rep0 3 条 + rep1 5 条 ⇒ 去重后 **5 个单元**
        α(填0) = 0.2174
        α(nan) = nan        ← 样本不足，算不出来（库报了 invalid value in scalar divide）
```

**5 个单元估 α 没有意义**（Krippendorff α 在小样本上方差极大）。

**而"样本少"不是偶然 —— 它是档 4 的固有特征**：
**槽位式约束太强，模型只能吐出三五条相符的关系。**

⇒ **这反而是主结论的一个侧面**：
**约束越强 ⇒ 输出越收敛（类型数 26→2），但也越少，少到不足以稳定估计一致性。**

## 四、修正后的主结论（比原来更精确）

**原表述**（只有第一篇时，写在 `P3_PROTOCOL_LADDER_RESULT.md` 里）：
> 「α 随协议结构化程度单调上升。」

**修正后**（两篇）：
> **协议结构化程度对标注一致性的影响是「分段」的：**
> - **从「完全开放」到「给定类型表」，α 有一次显著跃升**（两篇一致）；
> - **继续收紧到槽位式时，一致性不再上升**（第二篇回落）；
> - **而"模型实际用到的类型数"始终单调下降**（两篇完美单调）——
>   **约束越强，输出越收敛，但样本也越少。**
>
> ⇒ **「可标性」随结构化程度提升，但存在边际递减；
> 且过强的约束会把样本压到无法估计一致性的程度。**

**这比"单调上升"更有信息量** —— 它同时给出**方向**与**代价**，
而且与 **P5 的"槽位化只能覆盖 33.6%"互相印证**：
**两者都指向"过窄协议的代价"。**
