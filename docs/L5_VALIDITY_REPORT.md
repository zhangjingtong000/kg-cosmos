# L5 域内效度报告（人工式盲判 → 本项目分布上的真实指标）

> 生成于 2026-09-12。数据与脚本：
> `tools/l5_validity_sample.py`（分层抽样）→ 盲判 → `tools/l5_validity_report.py`（加权指标）
> → `tools/check_l5_agreement.py`（标注者间一致性）。
> 原始产物：`data/quality/l5-validity-{sample,key,labels,check}.jsonl|json`、

## 0. 一句话结论

**项目此前一直对外报的 "L5 = 63.7%" 是判别器的「通过率」，不是支持率、更不是精度。**
在 200 条分层抽样的人工式盲判下，本项目数据分布上的真实情况是：

| 指标 | 实测 | 此前报告 |
|---|---:|---:|
| **全图三元组被原文支持的比例** | **40.0%** | —（此前用 63.7% 通过率代替） |
| **判别器 PPV（判通过里真的被支持）** | **49.7%** | — |
| NPV（判不通过里真的不支持） | 23.0% | — |
| 召回（被支持者中被判通过） | 79.3% | — |
| F1 | 0.611 | — |
| 加权准确率 | 59.6% | — |
| **域内加权 AUC** | **0.7074** | 0.9851（官方英文校准集） |
| **与人工判定的 Cohen's κ** | **0.236** | — |
| 加权混淆（按全图规模） | TP 13778 / **FP 13960** / TN 12082 / FN 3604 | — |

**判通过的边里约一半不被原文支持；假阳性（13960）比真阳性（13778）还多。**

## 1. 这个数可不可信：标注者间一致性

盲判由**两个独立会话**完成（同 30 条重叠，见 `check_l5_agreement.py`）：

| | |
|---|---:|
| 共同标注 | 30 条 |
| 一致率 | **86.7%** |
| 期望一致率（随机） | 52.0% |
| **Cohen's κ** | **0.722** |
| 标注者 1 支持率 | **40.0%** |
| 标注者 2 支持率 | **40.0%** |
| 分歧 | 4 条（13%） |

判读准则**事先定好**：κ ≥ 0.6 ⇒ 任务可稳定标注、结论可用；0.4–0.6 ⇒ 需标注噪声；
< 0.4 ⇒ 不可稳定标注、只能报"一次读数"。**κ = 0.722 落在第一档**，
且两个标注者**独立得出完全相同的 40.0%**。

**限度（必须一并声明）**：两个标注者都是 **LLM**（不同会话），不是人类标注者。
κ 衡量的是"这个判定任务能否被稳定复现"，与标注者是不是人无关；
但**不能**据此声称达到了人类金标的水准。这一点限制了结论的强度，
不限制它的**方向**——40.0% 与 63.7% 的差距（23.7 个百分点）远超任何合理的标注噪声。

另有一道**隐藏探针**：11 条 `hit=none`（前提句里两个端点都没字面出现）的样本，
人工判「支持」的只有 1 条 = **9.1%**（期望接近 0%，>20% 则说明标注者把
"差不多的意思"当成了支持）。**探针通过**，说明这一轮标注没有系统性地放水。

## 2. 阈值是「数量旋钮」不是「质量旋钮」

用**同一份人工标签**重算各阈值（无需重新抽样）：

| 阈值 | 全图通过 | 通过率 | PPV | 召回 | F1 |
|---:|---:|---:|---:|---:|---:|
| 0.50 | 35329 | 77.3% | 47.9% | 47.9% | 0.479 |
| 0.60 | 31854 | 69.7% | 49.8% | 49.8% | 0.498 |
| **0.67** | 29074 | **63.6%** | **49.7%** | 49.7% | 0.497 |
| 0.75 | 25376 | 55.5% | 53.3% | 53.3% | 0.533 |
| 0.80 | 22629 | 49.5% | 56.7% | 56.7% | 0.567 |

> **口径**：`全图通过` / `通过率` 是**当前评测全集 45708 条边**上的读数
> （`data/quality/l5-validity-report.json` 的 `threshold_sensitivity`，字段
> `population_pass` / `pass_rate`）；`PPV` / `召回` / `F1` 来自人工标签，
> **不随图规模变化**。
> 本表此前一版写的是**旧图 43867** 口径：`33915 / 30599 / 27957 / 24436 / 21816`，
> 通过率 `77.3% / 69.8% / 63.7% / 55.7% / 49.7%`（2026-09-21 更正为当前口径；
> 旧值留档于此，因为它解释了为什么本报告正文别处仍会出现 63.7%）。

通过率随阈值下降是**恒等式**（"分数 ≥ 阈值"的定义），不构成质量证据。
有信息量的是 PPV：从 0.5 到 0.8，PPV 只从 47.9% 抬到 56.7%（+8.8pp），
而通过的边数减少了三分之一以上。

**⇒ 调阈值主要在调数量，不是在调对错。论文里不能写"调阈值提升了质量"。**

## 3. 一条独立于模型的结论：判别器对自环不敏感

`tools/check_l5_validity.py` 用**完全不依赖模型权重**的字面规则
（规范化后 `source == target` 的自环）估出通过集里的假阳性下界：

| 阈值 | 其中自环 | 规则下界 |
|---:|---:|---:|
| 0.50 | 236 | 0.696% |
| 0.60 | 229 | 0.748% |
| 0.67 | 223 | 0.798% |
| 0.75 | 203 | 0.831% |
| 0.80 | 189 | 0.866% |

**自环在通过集里的占比随阈值上升**（0.696% → 0.866%）——
即**提阈值并不能筛掉这类明显错误**。佐证：自环的通过率约 **91%**，而全集只有 63.7%。

## 4. 最反直觉的一条：简单字符串规则比 NLI 判别器更接近人工判定

| 代理指标 | 覆盖 | 命中率 | 与人工一致 | κ |
|---|---:|---:|---:|---:|
| **`hit=both`（两端点都出现在前提句里）** | 47% | 61.3% | **70.7%** | **0.407** |
| `hit≠none` | 94% | 41.7% | 44.4% | 0.058 |
| `hit=none` → 不支持 | 100% | 39.9% | 39.9% | 0.000 |
| 多论文独立提及（≥2 篇） | 9% | 29.4% | 56.6% | −0.043 |
| **判别器 `pass`** | 64% | 49.6% | 59.6% | **0.236** |

**`hit=both` 这个零成本的字符串规则的 κ（0.407）明显高于花了大代价的 NLI 判别器（0.236）。**

这不必然说明判别器无用（它覆盖 64% 而 `hit=both` 只覆盖 47%，
且它给出的是连续分数、可用于排序），但它说明：
**在"是否支持"这个二元判断上，判别器并不比"端点是否出现在句子里"这个字面线索更有信息量。**

结合 §0 的域内 AUC 0.7074（vs 官方校准集 0.9851），可以得出一个一致的解读：
**该判别器在官方校准集上学到的主要是"词汇重合"这类表面特征，
一旦换到本项目的数据分布就迅速退化。**

## 5. 这对项目意味着什么

1. **不能再用 63.7% 声称"63.7% 的三元组被原文支持"** ——
   正确说法是"判别器判通过 63.7%，其中约一半经独立盲判仍成立（PPV ≈ 50%）"。
2. **L5 作为"证据过滤"的实际收益被高估**：从 43867 条筛到 27954 条，
   但被筛掉的那 15913 条里有多少真的不该留、留下的里有多少其实不该留，
   现在有了答案：留下的里约一半不该留。
3. **这条负结果本身是论文素材**：它把"用现成 NLI 模型做证据过滤"
   这个常见做法在本任务上的失效过程完整记录了下来——
   包括**它为什么会失效**（校准集与目标分布不同构）与**怎么发现**
   （分层抽样 + 两个独立标注者 + 先定准则再看结果）。

## 6. 复现

```bash
# ① 分层抽样（产出 200 条盲判清单，含隐藏探针）
python tools/l5_validity_sample.py --n 200

# ② 盲判界面（零依赖；隐藏 entail_prob/pass/hit）
python tools/l5_validity_review.py     # → http://127.0.0.1:8097/

# ③ 把标签还原成本项目分布上的 PPV/召回/F1/AUC（加权）
python tools/l5_validity_report.py --labels data/quality/l5-validity-labels.jsonl

# ④ 标注者间一致性（决定结论可不可信）
python tools/check_l5_agreement.py

# ⑤ 可自动化部分 + 阈值灵敏度 + 盲判进度（已挂进回归）
python tools/check_l5_validity.py
```

前四步的人工部分已由两个独立会话完成（本报告即其结果）；
若要让**人类**标注者复核，用同一份 `l5-validity-sample.jsonl`，
换一个 `--labels` 文件名即可（`l5_validity_review.py --labels ...`），
再用 `check_l5_agreement.py` 比较。
