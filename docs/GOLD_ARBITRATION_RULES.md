# 金标仲裁规则（M2 标注判定细则）

> 来源：三方独立标注（A/B/C，不同阅读策略）的 20 条实体分歧与 92 条关系分歧，
> 经逐条归类后固化为本规则。目的是把"算不算实体/算不算关系"从主观判断
> 变成可机械执行的判据，否则同一份金标里会同时存在判对与判错的条目，
> P/R/F1 随之失去意义。
>
> 用法：仲裁者只依据本规则裁决分歧项，不重新发明标准。

## 1. 实体：收录的三个必要条件

一条实体必须**同时**满足：

1. **明确命名**：论文中出现了一个具体的名字（专有名词或论文自己定义的名词），
   而不是泛指短语
2. **承载语义**：它指代一个对象（系统/方法/概念/组织/数据/指标…），
   而不是一个描述或属性
3. **有句级依据**：能在正文、图注或表题中找到包含该名字的完整片段

## 2. 明确排除（无论依据多充分）

| 类别 | 例 | 理由 |
|---|---|---|
| 泛指短语 | `Domain Expert`、`Research Problem`、`Research Question`、`Semi-Structured Data`、`Bibliographic Data`、`Systematic Workflow` | 无具体所指，任何人读都指同一个泛类 |
| 图表编号 | `Figure 1`–`4`、`Table 1`–`4` | 文档结构标记，非语义对象 |
| 纯统计符号 | `95% CI`、`R0 estimates` | 数值/符号，非命名实体 |
| 示例/虚构数据 | `John Doe`、`Wuhan`、`Hubei Province`、`Joseph et al.` | 出自演示用示例表格，论文并不主张它们是研究对象 |
| 仅出现在参考文献/DOI 串 | `Zenodo` | 不是论文正文阐述的对象 |

## 3. 明确收录

| 类别 | 例 | 理由 |
|---|---|---|
| 论文自己命名的流程/方法步骤 | `Five-Step Methodology`、`Paper Selection`、`Table Extraction`、`Reference Extraction`、`Character Extraction` | 论文显式命名并反复引用，是方法的组成部分 |
| 对比基线系统 | `SemAnn`、`Web Tables`、`TableSeer`、`TEXUS` | 表 1 明确对比，属论文阐述对象 |
| 工具链 | `Tabula`、`GROBID`、`OpenRefine` | 明确命名的工具 |
| 与已收录实体语义重叠的别名 | `Relational Schema`（若 `Relational Database` 已收录，二者视为同一实体的不同指称，**只保留一个**） | 避免同一对象重复计数 |

**流程步骤的收录边界**：只有当论文把它当作**有名字的步骤**时才收录
（如 "Paper Selection" 是小节名/图 1 步骤名）；若只是句子里的动词短语
（如 "select papers manually"），不收录。

## 4. 关系：依据强度分级

关系必须两端都是已收录实体，且依据满足以下任一级：

| 级别 | 依据形式 | 是否收录 |
|---|---|---|
| 强 | 正文句子明确陈述两实体间关系 | ✅ 收录 |
| 中 | 表格行明确表达一个关系类型（如 `X \| USES \| Y` 式的对比行） | ✅ 收录 |
| 中 | 图注/表题明确表述 | ✅ 收录 |
| 弱 | 两实体仅并列出现（同句、同表、同段） | ❌ 不收录 |
| 弱 | 机构隶属仅靠上标编号表示 | ❌ 不收录（除非正文另有明确陈述） |

## 5. 票数门槛

- **实体**：≥2 票直接采纳；单票项按 §1–§3 裁决，符合则采纳，否则丢弃
- **关系**：≥2 票直接采纳；**单票关系一律不收录**（92 条单票关系中绝大多数属
  §4 的"弱依据"级别，收录会污染 Precision 口径）

## 6. 类型判定

同一实体在不同标注中类型不一致时，按以下优先级定：

1. 若它指一个**具名的系统/工具/平台** → `System`（其次 `Tool`）
2. 若它指一个**方法/算法/流程** → `Method`（步骤类用 `Process`）
3. 若它指**抽象的观念/术语** → `Concept`
4. 若它指**论文自己定义的产物**（表格表示、文件、模式） → `Artifact`
5. 若它指**具名组织/地点/人物/文献** → `Organization` / `Location` / `Person` / `Document`

## 7. 一致性门槛（论文里要报告的）

- 规则明确**前**：三方平均成对 Jaccard **69.9%**（实体层）
- 规则明确**后**：同批分歧项按本规则复核，报告复核后一致率
- 两条数字都进论文：前者说明任务本身的模糊度，后者说明规则收敛的效果
