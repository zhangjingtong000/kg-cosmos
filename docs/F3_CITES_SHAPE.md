## 二、抽样看：两端**大多不是论文**

```
Word2Vec   -> 'Pennington et al.'       ← **人名**，不是论文
ArXiv      -> 'Figure 2'                ← **图号**（抽取噪声）
Lao        -> Cohen                      ← **两个人名**
Bordes     -> KG Completion              ← **人 → 概念**
```

**⇒ "论文引用图"这个前提当场就不成立。**

---

## 三、量化（967 条 `CITES`）

### ① 形态

| 侧 | other | 两三个词的人名? | 出版串/年份 | **图表号噪声** | 姓+首字母 |
|---|---|---|---|---|---|
| 左侧（引用方） | 559 | 220 | 154 | **26** | 8 |
| 右侧（被引方） | 439 | 210 | **284** | **20** | 14 |

### ② 实体类型（混的）

```
左侧：Document 294 · Person 283 · Unknown 175 · Concept 72 · Method 67 …
右侧：Document 270 · Unknown 182 · Person 135 · Event 118 · Method 74 …
```

**⇒ 没有"论文"这个类别**（`Document` 里混着会议、仓库、图号）。
**`ArXiv` 是会议/仓库，不是"某篇论文"。**

### ③ ★ 被引方**一个都解析不到语料**

```
能对上**语料里的论文文件名**：  **0 / 967（0.0%）**
是图里存在的节点：              959 / 967（99.2%）
```

**⇒ 右边的东西在图里"存在"，但和 `data/corpus/graphs/` 里那 17 篇论文
没有任何一条能对上。** 也就是说：**这套 `CITES` 连不到"我们实际读过的那批论文"上。**

### ④ ★ 它**不是 DAG** ⇒ 不存在拓扑序

```
有向图：1119 节点 / 964 边
是 DAG：**False**
环的样例（2 个节点）：['A. Ng', 'Advances in Neural Information Processing Systems']
```

**⇒ 拓扑排序的第一前提（无环）就不满足。**
而那个环本身很说明问题：**一个人与一个会议互相引用** ——
那不是真实世界的引用关系，是**抽取把方向搞反或重复抽**。

---

## 四、结论与它的定位

**F3 的原始设想做不了，原因三重**：
1. **两端几乎没有"论文"节点**（大量人名、方法名，还有 `Figure 2` 这类噪声）；
2. **被引方 0% 能解析到语料** —— 它连不到我们真正读过的那批论文；
3. **图有环** —— 拓扑排序的前提不满足。

**⇒ 所以本项的处理不是"跳过"，而是"量清楚之后如实说明它做不了"。**

这与另外两处是同一类结论：
| 项 | 现象 | 性质 |
|---|---|---|
| **B3** | SciREX 关系层 `rtp = 0`（6/6 篇） | **数据/能力不支持** |
| **B4** | 消歧判据假阳性 27.4%，与 A5 同因 | **判据的边界** |
| **F3** | `CITES` 做不了拓扑排序 | **数据不支持** |

**⇒ 三处都不是"失败了"，而是"把边界量清楚了"。**

---

## 五、诚实的边界

| # | 边界 | 影响 |
|---|---|---|
| **1** | **只量了形态，没有尝试"清洗后重做"** | 理论上可以：只保留 `Document` 端、剔掉图表号、**去掉双向边破环** ⇒ 但**清洗到什么程度才算"论文引用图"是个需要拍板的口径问题**，而且它已经不叫 F3 了 |
| **2** | **"0% 解析到语料"是用文件名精确匹配算的** | 放宽（模糊匹配、标题匹配）会高一些，但**那需要论文标题表，而 `CITES` 右侧大量是人名 → 放宽也接不上** |
| **3** | **环只看了第一个** | `nx.simple_cycles` 在 1119 个节点上是可算的，但**"有环"这个结论一个反例就够** |
| **4** | **没有人类判断"这些 CITES 该不该存在"** | 判断"`Figure 2` 是噪声"是我按正则做的，**不是人工核过的** |

**第 1 条值得记下来**：**如果将来要做，那是一件独立的事**
（"清洗 `CITES` 造一个可用的引用图"），**不是 F3 的补做** ——
因为它要回答的是"什么才算一条引用"，那是个**口径决策**。
