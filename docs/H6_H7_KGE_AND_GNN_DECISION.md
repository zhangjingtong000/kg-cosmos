## 一、实验设置

| 项 | 值 |
|---|---|
| 数据 | `data/corpus/graphs/*.json`（17 篇）· **43867 条三元组** · 19469 个实体 · 15 类关系 |
| 模型 | TransE · RotatE（PyKeen），`embedding_dim=128`，Adam lr 1e-3，**100 epochs** |
| 评估 | realistic 设定（PyKeen 默认的过滤式排名） |
| 种子 | 20260916 |
| 耗时 | 253 秒（**CPU/GPU 均可，`torch 2.6.0+cu124`**） |

### 两种划分 —— **本实验最要紧的设计**

| 划分 | 训练/测试怎么分 | 回答什么 |
|---|---|---|
| **A · 按边随机** | 随机切 10% 的边 | 文献里报的那个数（**乐观**） |
| **B · 按论文** | 整篇留 3 篇（`1703.08098v9` / `2402.12001v1` / `2502.00681v2`），**训练时完全没出现** | **换一篇新论文还能不能预测** |

**B 才是这个项目真正关心的**：图谱是**逐篇论文抽出来的**，
而它的用途是"读一篇新论文时，帮我补出可能有但没抽到的关系"。
**A 的分数会被"同篇论文里的近邻边"抬高** —— 那些边在测试时仍见过同篇的其它边。

## 二、结果

```
划分        模型      MRR     Hits@1   Hits@3   Hits@10   耗时   新实体边%
by-edge   TransE   0.0398   0.0051   0.0546   0.1000    66s     19.0%
by-edge   RotatE   0.1270   0.1014   0.1301   0.1697    80s     19.0%
by-paper  TransE   0.0655   0.0134   0.0927   0.1556    45s     81.0%
by-paper  RotatE   0.1168   0.0966   0.1150   0.1467    53s     81.0%
```

### ★ 「新实体边%」这一列是本次实验最重要的产出

它是**测试集里"涉及训练时未见实体"的边所占比例**。这些边被**剔除**了 ——
**因为纯结构模型（TransE/RotatE，以及 GNN）给每个实体学一个嵌入向量，
而训练时没出现过的实体根本没有嵌入**，模型对它的打分是随机的。

```
by-edge   剔除  835 / 4386 = 19.0%
by-paper  剔除 4367 / 5394 = 81.0%   ← ★★★
```

**⇒ 换一篇新论文时，81% 的关系边涉及旧图完全没见过的实体。**
这不是模型调参能解决的 —— 是**数据形态**决定的。

## 三、H7：「不上 GNN」的数据支撑

> ### 🔁 2026-09-19 修订：本节标题与开头这句是**旧表述**，结论已被实测收窄
>
> **旧表述（留存）**：纪律原文要求把"没做"**升格为"评估过并有数据支撑的拒绝"**。
> 现在有两条：
>
> **修订为**：**"有数据支撑"成立，但它支撑的不是"不上 GNN"，而是"这个任务本身太难"。**
> 2026-09-19 补跑 GNN 实测（一次性实验脚本，
> 产物 `data/quality/_gnn-link-prediction.json`，结果文档 `docs/GNN_LINK_PREDICTION_RESULT.md`）
> 后，下面两条各自只对一半：
>
> | 旧理由 | 实测后成色 | 实测数字 |
> |---|---|---|
> | ① 81% 测试边涉新实体 ⇒ 纯结构方法无能为力 | **对一半**：真 inductive（B2）下确实失效（`GNN-ID` AUC **0.4780 < 随机 0.5013**），但**同一划分下带内容特征的模型是赢的**（`GNN-TYPE` 0.6113 / `GNN-TEXT` 0.5852 / 不用图的 `MLP-TEXT` 0.6404 vs 启发式 0.5337）⇒ **"跨论文 ⇒ 不上 GNN"推不出来** | `docs/GNN_LINK_PREDICTION_RESULT.md` |
> | ② 能测的 19% 上 Hits@10 只有 0.17 ⇒ 结构信号弱 | **这条才是站得住的理由**，且它**与用不用 GNN 无关**：B2 上**所有方法 Hits@10 ≤ 0.037**，换任何模型都一样 | 同上 |
> | （新增）H6 自己的口径 B1 上 GNN 反而最好 | **对「不上 GNN」不利，如实并列**：`GNN-TYPE` AUC **0.8161 > PA 0.7658**（`GNN-ID` 0.8066 / `GNN-TEXT` 0.8154） | 同上 |
>
> **一句话结论**：**不是「GNN 不适合」，而是「这个图谱本身没那么可预测，GNN 能赢但赢得不值得」。**

### ① **81% 的跨论文测试边涉及新实体** ⇒ 纯结构方法对它们无能为力

GNN 相比 KGE 的卖点是"利用邻域结构更好"，但**前提是那个实体在训练图里有邻域**。
**新实体在训练图里不存在** ⇒ **没有邻域可卷积**。
要处理它必须上 **inductive 方法**（用文本描述生成嵌入，如 KEPLER / 文本增强的 KGE），
**那是另一条技术路线，不是"KGE 换成 GNN"能解决的**。

### ② **能测的那 19% 上，最好的 Hits@10 只有 0.17** ⇒ 结构信号本身很弱

即便把新实体的问题绕开，**图谱自身的结构可预测性也不高**：

```
最好的组合（by-edge / RotatE）：Hits@1 = 0.1014，Hits@10 = 0.1697
```

**Hits@1 ≈ 10%** 意味着十次里对一次。
**⇒ 在这个信噪比下，GNN 多出来的那点结构建模能力不足以改变结论。**

### ③ **但 RotatE 明显强于 TransE**（MRR 0.127 vs 0.040）

这条是**反向证据，要如实说**：它说明**关系类型之间确实有可学的复杂模式**
（RotatE 用复数旋转建模对称/反对称/逆关系，TransE 的平移假设不够）。
⇒ **"结构里有信息"是真的，只是**量还不够**。**

## 四、诚实的边界

| # | 边界 | 影响 |
|---|---|---|
| **1** | **只有 17 篇、43867 条边** | 图谱规模小；更大规模下 KGE 的绝对指标通常会上升 |
| **2** | **`by-paper` 只留了 3 篇** | 换别的 3 篇，剔留比例会在 70%–90% 波动；**81% 是点估计，不是常数** |
| **3** | **100 epochs、默认超参** | 没有调参 ⇒ 这些数是**下界**，不是这些模型的上限 |
| **4** | **实体名未做全局归一** | 187 种「同一个东西的多种叫法」会让同一实体分成多个节点，**压低指标** |
| **5** | ~~**没跑 GNN**~~ **→ 2026-09-19 已补跑，此条作废** | **旧表述（留存）**：「所以「不上 GNN」的论证是**间接的**（依据新实体比例 + 结构可预测性），**不是"我们跑了 GNN 发现它更差"**」。**修订**：GNN 已于 2026-09-19 实跑（80 epoch / `elapsed_s` 940.0，`docs/GNN_LINK_PREDICTION_RESULT.md`），**且实测结果不支持"GNN 更差"** —— B1 上 GNN 反而最好（`GNN-TYPE` 0.8161 > PA 0.7658），B2 上 GNN-ID 低于随机（0.4780 < 0.5013）但带内容特征的 GNN 仍优于启发式。**⇒ 现在可以直说：我们跑过 GNN，结论是"任务本身太难"，不是"GNN 不适合"。** |

**旧文第 5 条的告诫留存（仍有价值，但对象已变）**：不得声称"我们评估过 GNN 所以拒绝它"。
**准确的说法是**：**"我们跑过 GNN（`docs/GNN_LINK_PREDICTION_RESULT.md`），它在 H6 口径下甚至最好、
在真 inductive 下低于随机；两种划分的相反画像说明结论取决于划分，而所有方法在跨论文设定下的
绝对指标都极低（Hits@10 ≤ 0.037）—— 这个图谱的链接可预测性本身就差。"**
